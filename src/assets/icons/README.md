# Weatherly Animated Weather Icons

Animated SVG icons matching the Weatherly illustration palette.

## Included

- sunny.svg
- partly-cloudy.svg
- cloudy.svg
- rainy.svg
- thunderstorm.svg
- snow.svg
- fog.svg
- clear-night.svg
- cloudy-night.svg

## React usage

```jsx
<img src="/icons/weatherly/rainy.svg" alt="Rainy weather" />
```

SVG animations work automatically in modern browsers. For accessible UI, keep the `alt` text or use `aria-label` when embedding inline.
